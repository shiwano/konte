# Muse

`konte` is not on PATH. Where a skill or konte's output says `konte`, run
this workspace's `.konte/bin/konte` by its absolute path.

The human cannot open this machine's loopback. Run `konte preview` with
`--tunnel`, and send its URL and PIN in the chat.

When a skill says to spawn a konte subagent, read its definition at
`.claude/agents/<name>.md` and spawn it fresh with the body as its
instructions.

A VM replacement ends every running process. Rerun a lost `konte job wait`;
for a lost `konte preview`, run `konte review record list` instead of a
second preview.
