# A piece that persuades

## The viewer's questions set the order

- **One claim, in the logline** — what the viewer believes or does afterwards; every shot is a reason for it, and a shot that is no reason is cut.
- **Order by the questions a viewer asks in turn** — what is it → is it for me → how does it work → can I trust it → what does it cost, what do I do. A surface the piece stands in for (a landing page, a store page) is usually already in this order; follow it.
- **Test: each shot answers the question the one before raised** — a shot answering a question nobody has asked yet is out of order.
- **Lens: `product-demo`** — its `problem` is the viewer's own situation, one beat.

## Prove, don't name

- **Each feature is one use on screen** — the notification arriving on the parent's phone; type may name it, the picture proves it.
- **One feature per shot** — two in a frame read as neither.
- **Brought material is the proof** — a real screen or product image goes in as itself; generate what surrounds it.
- **A figure demonstrates** — it uses the product, with no want, arc or relationship to resolve; ask the human who demonstrates, never invent a story around them.

## The obvious version within the form

- **The obvious persuasion is a flat list** — every feature at the same weight behind the same transition. Cull against it: one feature leads and the rest support it, and each transition is a consequence ("sent, so she pays, so the parent knows at once").
- **The hook is the claim or the problem, full size, in the first second** — never a logo.
- **The final image is the action** — the product, the offer, what to do next.
